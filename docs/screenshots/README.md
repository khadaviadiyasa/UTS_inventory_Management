# Screenshot checklist (tangkapan layar aktual)

Folder ini disiapkan untuk bukti visual hasil menjalankan aplikasi. Screenshot tidak dibuat sebagai mockup karena bukti harus berasal dari browser yang membuka Laravel pada database yang berjalan.

Setelah instalasi, login dan ambil screenshot tanpa menampilkan file `.env`, password, atau data pribadi:

1. `01-dashboard.png` — halaman Dashboard yang menampilkan kartu ringkasan, produk stok rendah, dan transaksi terbaru.
2. `02-products.png` — Product index yang menampilkan SKU, category, price, stock, filter/search.
3. `03-purchase-create.png` — form Purchase dengan supplier dan lebih dari satu item.
4. `04-purchase-detail.png` — detail purchase number, supplier, user, item, subtotal dan total.
5. `05-sales-create.png` — form Sales dengan kuantitas dan pratinjau total.
6. `06-sales-detail.png` — detail transaksi sales yang berhasil.
7. `07-insufficient-stock.png` — pesan error saat mencoba menjual melebihi stok dan bukti stok tidak berubah.
8. `08-test-run.png` — terminal yang menampilkan hasil `php artisan test`.

Gunakan Snipping Tool / `Win + Shift + S` di Windows, simpan dengan nama di atas. Jangan membuat atau mengubah screenshot agar terlihat seperti hasil pengujian yang tidak pernah dilakukan.
